# Reqor AI

**An AI-powered B2B request management platform designed to turn business email conversations into structured, trackable workflows.**

I built Reqor AI as a full-stack software project to explore how AI could automate repetitive business operations. The application combines request tracking, client management, email integrations, and AI-assisted classification to help teams organize and follow up on requests.

The project allowed me to work across frontend and backend development, authentication, relational databases, third-party API integrations, and AI-powered workflows.

**Tech stack:** Next.js, TypeScript, Tailwind CSS, Python, FastAPI, PostgreSQL, Redis, Celery, OpenAI API, Gmail API, and Microsoft Graph API.

**Project status:** Experimental prototype developed to strengthen my full-stack engineering skills before building Revealy AI. Some integrations and automated workflows may require additional configuration and validation.
